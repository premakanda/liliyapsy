# Лилия Янушкевич — психолог

Адаптивный сайт по утверждённому фиолетово-салатовому макету. React, TypeScript strict, Vite, CSS Modules. HTML генерируется при сборке; сервер приложению не требуется.

## Запуск

Нужен Node.js 22.12+ и npm. В PowerShell используйте `npm.cmd`, если политика системы блокирует `npm.ps1`.

```sh
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:51073/. Порт закреплён: если он занят, сервер завершится с ошибкой вместо переключения. Dev показывает 9 черновиков статей и 6 тематических страниц; FAQ содержит 22 вопроса, из них 11 выбраны для главной. Изменения YAML обновляют просмотр. Черновики статей и тем исключаются из публичной сборки.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
```

Сборка — `dist/`; проверочный сервер — http://127.0.0.1:4173/. Неизвестные адреса получают HTTP 404, каталоги перенаправляются на адреса с завершающим `/`.

## Где что лежит

- `AGENTS.md` — правила проекта.
- `src/assets/branding/` — используемый знак бренда.
- `src/assets/images/` — адаптивные портреты WebP 420/760/1080.
- `src/assets/illustrations/` — SVG-подложки первого экрана.
- `src/assets/icons/` — контурные иконки; `icons/requests/` — восемь геометрических иконок карточек запросов.
- `public/favicon.svg` — favicon по стабильному адресу.
- `docs/design/` — утверждённый макет, его облегчённая копия и ориентир десктопного логотипа. Эти файлы не используются интерфейсом.
- `docs/references/` — дополнительные схемы и образец блока «Обо мне».
- `src/content/site.yaml` — имя, hero, контакты и условия.
- `src/content/articles/`, `src/content/topics/` — рабочие черновики из комплекта; `src/content/faq.yaml` — ответы, вводный текст и список `homeIds` для блока главной.
- `src/components/` — интерфейс; `src/pages/` — страницы; `src/app/` — гидратация и SSG.
- `scripts/content.mjs` — единая валидация; `scripts/build.mjs` — HTML, sitemap и robots.
- `docs/PROJECT-STATUS.md` — актуальные согласованные факты, структура главной и ограничения.
- `docs/GIT-HANDOFF.md` — состав коммита, результаты проверок и команды для коммита/пуша.
- `.local/` — сохранённые исходные комплекты, неиспользуемые оригиналы, кэш и отчёты разработки; вся папка исключена из Git, ESLint и наблюдения Vite.

В корне остаются README, AGENTS, конфигурация проекта и стандартные рабочие каталоги. `node_modules/` и `dist/` создаются инструментами и не входят в коммит. Для запуска на новом компьютере достаточно репозитория и `npm ci`: локальный архив комплектов не требуется.

## Публикация

Статья включается в публичный список, HTML и маршруты только при `published: true`, реальной дате `publishedAt: YYYY-MM-DD` и подтверждённом `author`. Для темы нужен `published: true`; FAQ использует `publish: true`. Ошибки схемы и повторяющиеся slug останавливают сборку с указанием файла и поля. Сырой HTML в Markdown не исполняется.

Все статьи и темы сейчас остаются черновиками. Публичная сборка содержит 13 общих страниц и 404; dev дополнительно содержит 15 детальных страниц. Не включать публикацию ради наполнения интерфейса.

`siteUrl: null` сохраняет `noindex` и пустой sitemap. После подтверждения домена и готовности контента задайте реальный HTTPS URL: сборка добавит canonical и адреса sitemap. Правовые каркасы, стоимость без условий и отзывы без материалов исключены из индексирования. Перед запуском требуется отдельная проверка условий и юридических страниц.

Портрет — временный ИИ-образ. Подтверждённые контакты, длительность и сведения о практике находятся в YAML. Запись на главной ведёт к `#booking` с Telegram и почтой. Формы отправки, платежи, аналитика и календарь не подключены. Цены, образование, отзывы и адреса Instagram/Facebook не подставляются произвольно.

## Браузерная проверка

Запустите `npm run dev`, соберите проект и в другом терминале поднимите статическую сборку на отдельном порту 51074. PowerShell:

```powershell
$env:PORT = '51074'
npm.cmd run preview
```

Затем:

```sh
npm run test:browser
```

Нужен Chrome; для другого пути задайте `CHROME_PATH`. Адреса можно переопределить через `PREVIEW_URL` и `STATIC_PREVIEW_URL`. Playwright и axe проверяют шесть ширин главной, маршруты, ресурсы, якоря, вкладки, FAQ, фильтры, статический HTML, HTTP 404 и отсутствие черновиков в публичной сборке. Скриншоты и отчёт сохраняются в `.local/qa/browser/`. Дополнительные снимки на десяти ширинах: `node scripts/check-reference.mjs`.

## Размещение

Сайт пока локальный; DNS и хостинг не настраивались. Команда для статического хостинга — `npm run build`, каталог — `dist`. Платформа должна отдавать `404.html` со статусом 404 без SPA fallback. `_headers` подготовлен для совместимых платформ. CI выполняет lint, typecheck, тесты и build; автодеплоя нет.
