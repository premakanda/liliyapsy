# Проверка реализации

Дата: 8 ноября 2026 года.

## Пройдено

- `npm run typecheck`, `npm run lint`, `npm run build`, `npm test`.
- Пять тестов контента: исключение черновиков и скрытых FAQ; 9 статей / 6 тем / 18 вопросов редактору; запрет публикации без даты; одинаковые slug; включение подтверждённой статьи.
- Playwright в Chrome: главная и все типы внутренних страниц на 320, 375, 390, 768, 1024, 1440 px без горизонтального скролла.
- Визуально просмотрены скриншоты главной на 390, 768 и 1440 px и исходный макет. Все скриншоты сохранены в `.local/qa/`.
- Escape, возврат фокуса меню, переход из меню, раскрытие FAQ, поиск, фильтр статей, прямое открытие шести тем и черновика статьи.
- axe WCAG A/AA: главная, FAQ, статья — без автоматических нарушений. Это не полная ручная сертификация WCAG.
- `/about/` содержит контент и noindex в HTML без JavaScript; неизвестный адрес и черновик статьи получают HTTP 404 проверочным сервером.
- Локальный Manrope; WebP 420/760/1080 — около 29/59/86 КБ. Hero без lazy, нижний портрет с lazy.

## Ограничения

- Lighthouse не запускался. Нужна ручная проверка реальных телефонов и скринридера.
- Хостинг и DNS не подключены; их HTTP-поведение не проверено. Canonical отсутствует, sitemap пуст, страницы закрыты от индексации.
- 6 тематических страниц и 9 статей доступны только в dev до утверждения владельцем.
- Отзывы заменены переключаемыми принципами работы; правовые страницы — явно обозначенные каркасы.
- Канал записи, цены, длительность, образование и условия ожидают подтверждения. Отправки заявок нет.
- `npm audit`: 7 moderate предупреждений в цепочке dev-зависимости typescript-eslint → minimatch; runtime-зависимости без предупреждений. Принудительное понижение версии или замена major транзитивной зависимости не выполнялись. Проверить обновление инструментов перед настройкой CI в рабочем репозитории.

## Техническое решение

SSG использует Vite SSR build и React `renderToString` с гидратацией по [официальной документации Vite](https://vite.dev/guide/ssr.html). [gettpsy.ru](https://gettpsy.ru/) просмотрен как структурный ориентир. Его персональные данные, цены, отзывы и тексты не переносились.
