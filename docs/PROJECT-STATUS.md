## Ресурсы и локальная разработка

Рабочие ресурсы находятся в `src/assets/{branding,images,illustrations,icons}` и `public/favicon.svg`. Макеты — в `docs/design/` и `docs/references/`. Исходные комплекты и неиспользуемые оригиналы сохранены в игнорируемой `.local/`; они не нужны для сборки из чистого клона.

`npm run dev` использует только `127.0.0.1:51073` со строгой проверкой порта. Статический сервер для браузерных тестов запускается отдельно с `PORT=51074`. Исходники не зависят от содержимого `.local/`.
