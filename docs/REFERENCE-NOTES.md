# Дополнительные материалы владельца

Получены и просмотрены схемы [22.png](references/22.png) и [33.png](references/33.png). Это пояснения к заданию: структура, бренд, иконки, контент и качество реализации. Основной визуальный образец страницы — `docs/design/design-reference-full.png` и присланный владельцем скриншот главной.

## Общие требования

- React, TypeScript strict, Vite, CSS Modules; статический сайт без backend, авторизации и CMS.
- Светлая сиренево-фиолетовая система с лаймовыми акцентами, крупные жирные заголовки, округлые карточки и тонкие контурные иконки.
- Двухцветный росток: знак с именем на десктопе, отдельный знак на мобильном.
- Главная: hero, преимущества, запросы, процесс и подход, знакомство, услуги, отзывы при наличии разрешённых материалов, статьи, FAQ, финальная запись.
- Mobile First, адаптивные WebP, доступная навигация, семантический HTML, локальные шрифты, metadata и статические страницы статей.
- Статьи и FAQ редактируются в YAML. Примеры на изображениях объясняют формат и не являются материалами, утверждёнными к публикации.

## Сопоставление разных версий

| Различие в схемах | Решение для текущего проекта |
| --- | --- |
| Разные HEX-коды фиолетового, сиреневого и лайма | Сохраняется палитра согласованного макета и действующего `AGENTS.md`; автоматическая замена цветов по одному из плакатов не выполняется. |
| Cloudflare Pages в одной схеме, Vercel в другой | Хостинг остаётся не настроенным. Материалы не определяют однозначную платформу и не подтверждают публикацию. |
| Пример `/articles/:slug` без завершающего слеша | Сохраняется единый формат `/articles/<slug>/`, установленный подробным заданием. |
| Упрощённая YAML-модель с `date`, `image`, `excerpt` | Сохраняется действующая валидируемая модель с `published`, `publishedAt`, `coverImage`, `description`; она защищает от случайной публикации черновиков. |
| Предложение использовать аналогичные формулировки gettpsy.ru | Сохраняются собственные тексты из комплекта; структурный референс не подменяет факты о Лилии или подтверждение авторских материалов. |
| Образование, опыт, отзывы, мессенджеры и график перечислены как будущие блоки | Их присутствие на схеме не подтверждает реальные сведения. Публикация зависит от предоставленных владельцем данных. |
| Портрет обозначен как фото специалиста | По текущему подтверждённому статусу это временный ИИ-образ; подпись и alt сохраняют честное описание. |

В этом шаге изображения перенесены из корня в `docs/references/`, требования зафиксированы в документации. Интерфейс, данные, зависимости и настройки публикации не изменялись; повторная сборка для этих изменений не требовалась.
