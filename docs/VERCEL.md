# Ознакомительная публикация в Vercel

Опубликовано 9 ноября 2026 года: **https://liliyapsy.vercel.app/**. Проект — `premakandas-projects/liliyapsy`. Проверены все 48 страниц: HTTP 200, `noindex` в HTML и заголовках; неизвестный адрес возвращает HTTP 404. Sitemap пуст.

Публикация выполнена через CLI. Автоматическая привязка GitHub не удалась из-за отсутствия доступа интеграции к репозиторию; автопубликация после пуша не настроена. Для её включения нужно предоставить приложению Vercel доступ к `premakanda/liliyapsy` в GitHub и подключить репозиторий в настройках проекта Vercel.

Проект подготовлен как статический сайт: Vercel выполняет `npm ci`, затем `npm run build` и публикует каталог `dist`. Настройки находятся в `vercel.json`. Используются готовые HTML-страницы с завершающим `/`, без SPA-перенаправления всех адресов на главную. Неизвестные адреса должны возвращать настоящий HTTP 404.

## Запрет индексации

- На всех путях Vercel установлен HTTP-заголовок `X-Robots-Tag: noindex, nofollow`, включая production-публикацию.
- В HTML каждой страницы сохраняется `<meta name="robots" content="noindex,follow">`, поскольку `siteUrl: null`.
- Sitemap пуст. `robots.txt` разрешает обход, чтобы поисковые роботы могли прочитать `noindex`.

Запрет индексации не ограничивает доступ по ссылке. Для закрытого просмотра потребуется отдельно включить защиту доступа Vercel.

Перед открытием индексации нужно согласовать запуск, изменить заголовок в `vercel.json`, задать подтверждённый `siteUrl` и выполнить новую публикацию.

## Публикация

Можно импортировать GitHub-репозиторий `premakanda/liliyapsy` в аккаунт Vercel: настройки сборки прочитаются из `vercel.json`. Для CLI необходим вход в аккаунт:

```sh
npx vercel login
npx vercel --prod --scope premakandas-projects
```

Файл `.vercelignore` исключает локальные архивы, зависимости и результаты предыдущих сборок из загрузки. Локальная привязка `.vercel/` не попадает в Git. Токены доступа не добавляются в репозиторий.

После публикации проверить главную, каталог `/articles/`, одну статью, неизвестный адрес и наличие `X-Robots-Tag` в ответах. Успешная локальная сборка сама по себе не подтверждает публикацию.

Справка: [конфигурация Vercel](https://vercel.com/docs/project-configuration/vercel-json), [правила noindex](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag).
